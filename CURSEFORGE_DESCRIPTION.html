CommandCore+: The Ultimate Command Collection

More commands. More control. Your Minecraft world, your rules!

⚡ Give Minecraft a whole new set of commands with CommandCore+. From setting homes and teleporting between players to managing your world, controlling gameplay and using powerful admin utilities, CommandCore+ brings a huge collection of commands together in one mod. ⚡

Tired of installing multiple mods just to get useful commands? CommandCore+ aims to bring everything together. Whether you're playing survival, exploring with friends or managing a multiplayer server, there's a command for almost everything.

🔥 59 planned command names. Two mod loaders. One command-focused mod. 🔥

⚡ Main Features

  • Home system: Save locations, teleport home, manage multiple homes and rename saved locations.
  • Player teleportation: Send teleport requests, accept or deny requests and return to previous locations.
  • Warps and spawn: Create warps, manage destinations and set your server's spawn or hub.
  • Player utilities: Check coordinates, find nearby players and view player information.
  • World controls: Change the time and weather and view information about your world.
  • Admin utilities: Access commands for healing, feeding, flight, god mode and vanish.
  • Server management: Broadcast messages, display rules and manage server information.
  • Extra utilities: Nicknames, hats, trash and additional inventory-related commands.
  • Two mod loaders: Separate builds for Fabric and NeoForge.

🏠 Home Commands

  • /sethome – Save your current location as a home.
  • /home – Teleport to a saved home.
  • /homes – View your saved homes.
  • /delhome – Delete a saved home.
  • /renamehome – Rename an existing home.
  • /homeinfo – View information about a saved home.

🌀 Teleportation Commands

  • /tpa – Request to teleport to another player.
  • /tpahere – Request another player to teleport to you.
  • /tpaccept – Accept a teleport request.
  • /tpdeny – Deny a teleport request.
  • /tpacancel – Cancel your teleport request.
  • /back – Return to your previous tracked location.
  • /rtp – Use random teleport.
  • /wild – Random wilderness teleport utility.

🌎 Spawn & Travel Commands

  • /spawn – Teleport to the saved spawn.
  • /setspawn – Set the spawn location.
  • /hub – Go to the hub warp.
  • /sethub – Set the hub warp.
  • /warp – Teleport to a warp.
  • /warps – View available warps.
  • /setwarp – Create a warp.
  • /delwarp – Delete a warp.

👤 Player Utility Commands

  • /near – Find nearby players.
  • /coords – Display your coordinates.
  • /sendcoords – Send your coordinates to another player.
  • /ping – Ping information utility.
  • /playtime – Playtime utility.
  • /whois – View information about an online player.
  • /seen – Check a player's online status.

🛡️ Safety & Location Commands

  • /unstuck – Help move out of a stuck position.
  • /deathpoint – Death location utility.
  • /lastdeath – Last death location utility.
  • /recover – Recovery utility.
  • /whereami – Display your current location.

🌤️ World Utility Commands

  • /day – Set the world to daytime.
  • /night – Set the world to nighttime.
  • /weather – Change the world weather.
  • /ptime – Personal time utility.
  • /pweather – Personal weather utility.
  • /worldinfo – Display world information.

⚙️ Server Management Commands

  • /broadcast – Send a server-wide announcement.
  • /motd – Message of the day utility.
  • /rules – Display server rules.
  • /list – View online players.
  • /clearchat – Clear chat using blank messages.
  • /maintenance – Maintenance utility.

🔨 Admin Commands

  • /fly – Flight utility.
  • /heal – Restore health.
  • /feed – Restore hunger.
  • /god – God mode utility.
  • /invsee – Inventory slot information utility.
  • /endersee – Ender chest slot information utility.

✨ Extra Commands

  • /nick – Set a custom visible name.
  • /hat – Equip your held item as a hat.
  • /trash – Discard an item with confirmation.
  • /craft – Crafting utility.
  • /enderchest – Ender chest utility.
  • /workbench – Workbench utility.

🧱 Mod Loaders

CommandCore+ is being developed for two popular Minecraft Java mod loaders:

  • Fabric: A separate Fabric build.
  • NeoForge: A separate NeoForge build.

Download the JAR that matches your installed mod loader. Do not put both loader versions into the same installation.

🔧 Installation

  1. Download the CommandCore+ JAR for your mod loader.
  2. Install the matching version of Fabric or NeoForge.
  3. Place the downloaded JAR inside your Minecraft mods folder.
  4. Launch Minecraft using your selected mod loader.
  5. Join a world and try the available commands.

🔐 Permissions

  • Some commands require operator permissions.
  • Administrative commands are intended for players with the appropriate permissions.
  • Command availability may depend on the current version of the mod.

🚧 Development Notes

CommandCore+ is actively being developed. The command list includes planned and partially implemented utilities, so not every listed command is fully functional in the current release. Check the changelog for updates to command availability and functionality.
